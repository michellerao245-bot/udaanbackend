# 🚀 Udaan SaaS Backend

Multi-tenant SaaS backend for FMCG Sales & Distribution Management.

## 📊 Tech Stack

• **Runtime:** Node.js + Express
• **Database:** Supabase (PostgreSQL)
• **Auth:** JWT + bcrypt
• **Payment:** PhonePe (KYC pending)

## 🚀 Quick Start

### Prerequisites
• Node.js v18+
• Supabase account
• PhonePe Business account (optional)

### Installation

```bash
# Clone repo
git clone [repo-url]
cd backend

# Install dependencies
npm install

# Setup environment
cp .env.example .env
# Edit .env with your credentials

# Start server
npm run dev
